Create `mal.py` with two pure functions (no class needed):

1. `matchability_score(ious: Tensor, cls_scores: Tensor, gamma: float = 1.5) -> Tensor`:
   - Computes `ious.pow(gamma) * cls_scores.pow(1.0 - gamma)` (MAL-01)
   - `ious` shape [num_fg], `cls_scores` shape [num_fg], returns [num_fg]
   - Both inputs should be in [0, 1]. `ious` comes from assignment (detached). `cls_scores` is sigmoid-activated prediction for the matched GT class (carries gradients).

2. `mal_weight(matchability: Tensor, eps: float = 1e-8) -> Tensor`:
   - Uses bounded formulation: `(1.0 - matchability).pow(2) + 1.0` (MAL-02)
   - Returns 1.0 at matchability=1.0 (BCE equivalence), max 2.0 at matchability=0.0
   - The `eps` param is unused with this formulation but kept for API stability

Both functions: full type annotations, docstrings referencing requirement IDs.

Create `tal.py` with `TaskAlignedAssigner` class (TAL-01):

- `__init__(self, topk: int = 13, alpha: float = 1.0, beta: float = 6.0, num_classes: int = 80) -> None`
- `assign(self, batch_idx, num_gt, total_num_anchors, gt_bboxes_per_image, gt_classes, bbox_preds, cls_preds, obj_preds, expanded_strides, x_shifts, y_shifts)` -- MUST have identical signature to `DINOXHead._get_assignments` and return the same 5-tuple: `(gt_matched_classes, fg_mask, pred_ious_this_matching, matched_gt_inds, num_fg)`.

Implementation details for `assign`:
- Call `_get_in_boxes_info` (import from dinox_head) for spatial filtering. NOTE: `_get_in_boxes_info` is a method on DINOXHead, so TAL needs it passed in or duplicated. Since TAL is a separate class, duplicate the spatial filtering logic as a module-level function `_get_in_boxes_info` in `tal.py` (same pattern as SimOTA being self-contained in dinox_head.py). Copy the logic from `DINOXHead._get_in_boxes_info` (lines 964+).
- Also need `_bboxes_iou` -- import from `dinox_head` since it's already a module-level function there.
- Compute alignment metric: `bbox_scores.pow(alpha) * pair_wise_ious.pow(beta)` where `bbox_scores[g, a]` = sigmoid cls_pred at anchor a for GT class g.
- Select `min(topk, num_candidates)` per GT by alignment metric.
- Apply spatial constraint (multiply matching_matrix by is_in_boxes_and_center).
- Resolve multi-GT conflicts: keep assignment with highest alignment metric (not lowest cost -- TAL uses max alignment, not min cost).
- Handle edge case: if no candidates remain after spatial filtering, return zero-fg tuple (same format as SimOTA's early return).
- All computation inside `torch.no_grad()` (same as SimOTA assignment).

Update `__init__.py`: add imports for `matchability_score`, `mal_weight`, `TaskAlignedAssigner`.

  ```python
  cls_loss_raw = self.bcewithlog_loss(cls_preds[batch_idx][fg_mask], cls_target)
  if self.use_mal:
      cls_sigmoid = cls_preds[batch_idx][fg_mask].sigmoid()
      matched_cls_idx = gt_matched_classes.to(torch.int64)
      cls_score_for_gt = cls_sigmoid[torch.arange(len(matched_cls_idx), device=cls_sigmoid.device), matched_cls_idx]
      m = matchability_score(pred_ious_this_matching, cls_score_for_gt, self.mal_gamma)
      w = mal_weight(m)
      cls_loss += (cls_loss_raw * w.unsqueeze(-1)).sum()
  else:
      cls_loss += cls_loss_raw.sum()
  ```
  CRITICAL: `pred_ious_this_matching` is already detached (from assignment). Only `cls_score_for_gt` carries gradients. This avoids circular gradient dependency (MAL-03).
