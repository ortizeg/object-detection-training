class TestDFLModule:
- test_output_shape: DFLModule(16).forward(torch.randn(10, 68)) -> shape [10, 4]

- test_gradient_flows: Create input with requires_grad=True, run forward, call .sum().backward(), verify input.grad is not None and not all zeros
- test_different_reg_max: DFLModule(8).forward(torch.randn(5, 36)) -> shape [5, 4]

class TestDistributionFocalLoss:
- test_output_shape: distribution_focal_loss(torch.randn(10, 17), torch.rand(10)*15.99) -> shape [10]
- test_gradient_flows: Verify gradients flow through distribution_focal_loss
- test_integer_target: For target=5.0 exactly, loss should be equivalent to standard cross_entropy at bin 5
- test_midpoint_target: For target=5.5, loss should be weighted average of CE at bins 5 and 6 with equal weights (0.5 each)
- test_boundary_target: For target=0.0, all weight on bin 0. For target near reg_max, all weight on last bin.

All tests use pytest, torch, proper imports and type annotations.
