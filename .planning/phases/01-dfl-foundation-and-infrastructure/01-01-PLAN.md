**dinox_head.py** - Create DINOXHead as a fresh nn.Module (NOT subclass of YOLOXHead, per research recommendation). Reuse building blocks (BaseConv, DWConv from yolox.network_blocks). Follow YOLOXHead's decoupled head pattern exactly:

Constructor params: num_classes, width (0.75 for M), strides ([8,16,32]), in_channels ([256,512,1024]), act ("silu"), depthwise (False), use_dfl (False), reg_max (16)

Layers (per FPN level, matching YOLOXHead):
- stems: BaseConv(in_ch, 256*width, 1, 1, act)
- cls_convs: 2x BaseConv(256*width, 256*width, 3, 1, act) -- or DWConv if depthwise
- reg_convs: 2x BaseConv(256*width, 256*width, 3, 1, act) -- or DWConv if depthwise
- cls_preds: Conv2d(256*width, num_classes, 1)
- obj_preds: Conv2d(256*width, 1, 1)
- reg_preds: Conv2d(256*width, 4*(reg_max+1) if use_dfl else 4, 1)
- If use_dfl: self.dfl = DFLModule(reg_max)

Key methods:
1. `initialize_biases(prior_prob)` - same as YOLOXHead: cls_preds and obj_preds bias = -log((1-p)/p)
2. `forward(xin, targets=None, labels=None)` - training vs inference branching:
   - **Inference (no targets)**: Concatenate decoded predictions across FPN levels into [B, N, 5+num_classes]. For DFL mode: run DFLModule on reg output, convert LTRB to CXCYWH using anchor points and strides, then concat [cx, cy, w, h, obj, cls...]. For non-DFL mode: use standard YOLOX exp-based decode. Return single tensor.
   - **Training (with targets)**: Concatenate raw outputs (reg, obj, cls) across FPN levels. Call `get_losses(...)` to compute SimOTA assignment and loss.
3. `get_output_and_grid(output, k, stride, dtype)` - reshape concatenated FPN output, generate grid/anchor points. Channel count = (4*(reg_max+1) if use_dfl else 4) + 1 + num_classes.
4. `get_losses(...)` - Follow YOLOXHead.get_losses pattern:
   - Use SimOTA assignment from YOLOXHead (import `bboxes_iou` from yolo_head)
   - For DFL: after SimOTA assigns positive samples, decode DFL distributions to CXCYWH for IoU loss, compute DFL loss on raw distributions using `distribution_focal_loss` against LTRB targets converted from GT CXCYWH
   - Combined loss: total = iou_loss + conf_loss + cls_loss + dfl_loss_weight * dfl_loss (when use_dfl) or total = iou_loss + conf_loss + cls_loss (standard)
   - L1 loss: compute on decoded CXCYWH boxes (same as YOLOX) when self.use_l1 is True
   - Return dict: {"total_loss", "iou_loss", "conf_loss", "cls_loss", "l1_loss", "dfl_loss" (if use_dfl), "num_fg"} -- must include l1_loss even if 0.0 for compatibility

CRITICAL coordinate handling:
- Write helper `_ltrb_to_cxcywh(ltrb, grid, stride)` converting DFL LTRB output to pixel CXCYWH
- Write helper `_cxcywh_to_ltrb_target(gt_cxcywh, grid, stride, reg_max)` converting GT boxes to DFL targets (clamp to [0, reg_max])
- Both helpers are used in get_losses and in inference decode

Important: Copy the SimOTA assignment logic from YOLOXHead (get_assignments, dynamic_k_matching, etc.) into DINOXHead. Do NOT import internal methods from YOLOXHead -- it's third-party code we can't modify. The assignment code is ~200 lines but must be self-contained.

ONNX compatibility: In inference forward path, the DFL integral (softmax + weighted sum) must be part of the forward graph. No conditional branches on self.training -- use `if targets is not None` instead (traces cleanly for ONNX).

- Match YOLOX class structure exactly (see yolox/__init__.py YOLOX class)

**Update __init__.py** to export DINOXHead and DINOX.
