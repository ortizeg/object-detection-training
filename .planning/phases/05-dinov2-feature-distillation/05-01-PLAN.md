**distillation.py** -- Create `DistillationModule(nn.Module)` with:
- Constructor args: `student_channels: list[int]` (e.g. [192, 384, 768] for YOLOX-M width=0.75), `teacher_embed_dim: int = 768`, `teacher_layer_indices: list[int] | None = None` (default [3, 7, 11] for 0-indexed ViT-B blocks), `distill_weight: float = 0.5`, `teacher_model: str = "dinov2_vitb14"`
- Load teacher via `torch.hub.load('facebookresearch/dinov2', teacher_model, pretrained=True)`. Set ALL teacher params `requires_grad=False`. Call `self.teacher.eval()`.
- Register ImageNet normalization buffers: `mean=[0.485, 0.456, 0.406]`, `std=[0.229, 0.224, 0.225]` as `(1,3,1,1)` tensors via `register_buffer`.
- Create `self.projectors = nn.ModuleList` with one `nn.Sequential(nn.Conv2d(c_in, teacher_embed_dim, 1, bias=False), nn.BatchNorm2d(teacher_embed_dim))` per student channel.
- `assert len(student_channels) == len(teacher_layer_indices)` in constructor.
- Override `train(mode=True)` to keep teacher in eval mode always: `super().train(mode); self.teacher.eval(); return self`.
- `forward(self, images: torch.Tensor, student_features: list[torch.Tensor]) -> torch.Tensor`:
  1. Preprocess images: BGR->RGB via `images[:, [2, 1, 0], :, :]`, then normalize `(rgb / 255.0 - self.mean) / self.std`
  2. Teacher forward inside `torch.no_grad()`: `teacher_features = self.teacher.get_intermediate_layers(images_norm, n=self.teacher_layer_indices, reshape=True)`
  3. For each level k: project student feature via `self.projectors[k]`, bilinear interpolate to teacher spatial size `F.interpolate(projected, size=(teacher_feat.shape[2], teacher_feat.shape[3]), mode='bilinear', align_corners=False)`, compute `F.mse_loss(projected, teacher_feat.detach())`
  4. Return sum of per-level losses (NOT multiplied by distill_weight here -- the Lightning model applies the weight)

**dinox_lightning.py** -- Modify `DINOXLightningModel`:

1. **Constructor**: Add new params `enable_distillation: bool = False`, `distill_weight: float = 0.5`, `distill_layer_indices: list[int] | None = None`, `distill_teacher: str = "dinov2_vitb14"`. Store as instance attrs. Pass `enable_distillation` to `DINOXConfig(...)` validation call. After `self.model = DINOX(...)` is built, conditionally create distillation:
```python
if enable_distillation:
    from object_detection_training.models.dinox.distillation import DistillationModule
    student_channels = [int(c * width) for c in in_channels]
    self.distillation: DistillationModule | None = DistillationModule(
        student_channels=student_channels,
        teacher_layer_indices=distill_layer_indices or [3, 7, 11],
        distill_weight=distill_weight,
        teacher_model=distill_teacher,
    )
    logger.info(f"Distillation enabled: teacher={distill_teacher}, weight={distill_weight}, layers={distill_layer_indices}")
else:
    self.distillation = None
```

2. **forward()**: No changes needed. The existing `_export_mode` branch already only calls `self.model(images)`, naturally excluding distillation. The training branch already returns `outputs` from `self.model(images, targets)` which now includes `fpn_features`.

3. **training_step()**: After computing `loss = outputs["total_loss"]`, add distillation loss:
```python
if self.distillation is not None:
    fpn_features = outputs.get("fpn_features")
    if fpn_features is not None:
        distill_loss = self.distillation(images, list(fpn_features))
        loss = loss + self.distillation.distill_weight * distill_loss
        self.log("train/distill_loss", distill_loss, on_step=True, on_epoch=True, prog_bar=False)
```
Note: `images` at this point is the RGB input from the batch. But the forward() method converts to BGR before passing to self.model. The DistillationModule expects BGR (raw YOLOX pipeline format) and handles BGR->RGB internally. So we need to pass the BGR images. Store `images_bgr` after the RGB->BGR conversion in forward(), or better: extract fpn_features in training_step by calling `images_bgr = images[:, [2, 1, 0], :, :]` (matching the forward() conversion) and pass that to distillation. Actually, look at forward(): `images = images[:, [2, 1, 0], :, :]` is done in-place on the variable. So in training_step, `images` from the batch is RGB. We need BGR for the distillation module. Do: `images_bgr = images[:, [2, 1, 0], :, :]` in training_step and pass to distillation.

4. **configure_optimizers()**: After the existing loop over `self.model.named_modules()`, add projector params if distillation is enabled:
```python
if self.distillation is not None:
    for k, v in self.distillation.projectors.named_modules():
        if hasattr(v, "bias") and isinstance(v.bias, nn.Parameter):
            pg2.append(v.bias)
        if isinstance(v, nn.BatchNorm2d) or "bn" in k:
            pg0.append(v.weight)
        elif hasattr(v, "weight") and isinstance(v.weight, nn.Parameter):
            pg1.append(v.weight)
```
Do NOT iterate over `self.distillation.teacher` -- its params must stay frozen and out of optimizer.

5. **Logging init**: Update the logger.info line to include `enable_distillation={enable_distillation}` in the init message.
