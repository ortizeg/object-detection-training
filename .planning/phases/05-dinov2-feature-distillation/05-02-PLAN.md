  <action>
Create `tests/test_dinox_distillation.py` with the following tests. Use `pytest` and `torch`. Follow the existing test pattern: duplicate helper functions (do NOT import from other test files per project decision).

**Helper functions:**
- `_make_distillation_module() -> DistillationModule`: Creates module with `student_channels=[192, 384, 768]`, default teacher layer indices `[3, 7, 11]`. Mark with `@pytest.fixture` or use as factory. Note: this downloads the DINOv2 model on first run -- mark tests that need real teacher with `@pytest.mark.slow` if torch.hub download is needed. For most tests, mock the teacher to avoid network dependency.
- For tests needing actual teacher behavior, use a fixture that checks `torch.hub` cache availability and skips if offline.

**Test 1: test_teacher_frozen** -- Instantiate DistillationModule. Assert ALL teacher parameters have `requires_grad=False`. Assert `self.teacher.training == False`. Call `module.train()` and assert teacher is STILL in eval mode.

**Test 2: test_projector_output_shape** -- Create module with `student_channels=[192, 384, 768]`. For each projector k, feed a dummy tensor `(2, C_k, H_k, W_k)` where (H,W) are (80,80), (40,40), (20,20). Assert projector output shape is `(2, 768, H_k, W_k)` (before interpolation).

**Test 3: test_spatial_alignment** -- Feed module.forward() with dummy images `(2, 3, 640, 640)` and student features at correct spatial sizes. The teacher produces 45x45 spatial output for 640x640 input. Assert the distillation loss is a scalar tensor with grad. For this test, mock the teacher's `get_intermediate_layers` to return tensors of shape `(2, 768, 45, 45)` to avoid downloading the model.

**Test 4: test_zero_loss_identity** -- The critical TEST-04 requirement. Create a DistillationModule. Mock the teacher to return known features. Create student features that, after projection and interpolation, exactly match the teacher features. Use identity-like projectors (set Conv2d weights to identity mapping when student channels == teacher channels for P5 level at 768). For the 768->768 case: set conv weight to identity (diag ones in the correct 4D shape), BN to identity (weight=1, bias=0, running_mean=0, running_var=1, eps matching). Feed matching features. Assert loss is 0.0 (within tolerance 1e-5).

**Test 5: test_preprocessing_bgr_to_rgb** -- Create module. Feed BGR image tensor (e.g., channel 0=100, 1=150, 2=200). Mock teacher forward to capture input. Assert teacher receives RGB-ordered, ImageNet-normalized input. Specifically: after BGR->RGB, channel values should be [200, 150, 100] / 255.0, then normalized by ImageNet mean/std.

**Test 6: test_config_distillation_fields** -- Assert DINOXConfig accepts `enable_distillation=True`, `distill_weight=0.5`, `distill_layer_indices=[3,7,11]`, `distill_teacher="dinov2_vitb14"`. Assert defaults: `enable_distillation=False`, `distill_weight=0.5`.

**Test 7: test_dinox_fpn_features_exposed** -- Create a DINOX model. Run forward with dummy targets. Assert `"fpn_features"` key exists in the output dict. Assert it's a tuple/list of 3 tensors. Assert inference forward (no targets) does NOT contain fpn_features.

**Test 8: test_distillation_not_in_onnx** -- Create DINOXLightningModel with `enable_distillation=True` (will need to mock torch.hub.load to avoid network). Set export mode. Trace forward with dummy input. Assert the distillation module's teacher and projectors are not in the traced graph (the export path only calls self.model).

**Test 9: test_projector_params_in_optimizer** -- Create DINOXLightningModel with `enable_distillation=True` (mock teacher). Call `configure_optimizers()`. Collect all param ids from optimizer param groups. Assert projector conv weights and BN params are present. Assert NO teacher params are present (check by param id comparison).

**Mocking strategy:** Use `unittest.mock.patch('torch.hub.load')` to return a mock teacher that:
- Has a `.parameters()` returning some dummy params with `requires_grad` checkable
- Has `.get_intermediate_layers()` returning list of `(B, 768, 45, 45)` tensors
- Has `.eval()` and `.train()` methods
- The mock should be an `nn.Module` subclass so it works with `register_buffer` etc. Consider creating a `FakeTeacher(nn.Module)` class in the test file for this purpose.

For tests requiring DINOXLightningModel, also mock `download_checkpoint` and checkpoint loading to avoid needing real weights. Set `download_pretrained=False` and `pretrain_weights=None` where possible, or mock `_download_and_load_weights`.
