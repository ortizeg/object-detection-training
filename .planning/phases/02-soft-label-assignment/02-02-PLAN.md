  <action>
Create `tests/test_dinox_soft_labels.py` with the following test classes. Use pytest, torch, and F (torch.nn.functional). Import DINOXConfig from config, DINOXHead from dinox_head, DINOX from dinox, and YOLOPAFPN. Reuse the `_make_model` and `_make_targets` helpers from test_dinox_head.py (import them).

**class TestSoftLabelTargets:**
Tests for SIMO-01 (IoU^gamma weighted classification targets).

- `test_iou_gamma_weighting_values`: Create known IoU tensor `[0.8, 0.5, 0.3]` with gamma=2.0. Expected soft weights: `[0.64, 0.25, 0.09]`. Compute `ious.pow(gamma)` and assert `torch.allclose` with atol=1e-6. Then build one-hot for 2 classes (all class 0) and multiply by weights. Assert class 0 column equals expected weights, class 1 column is all zeros.

- `test_gamma_zero_produces_binary_targets`: gamma=0 should make `IoU^0 = 1.0` for all positive samples regardless of IoU value. Create IoUs `[0.8, 0.5, 0.1]`, compute `.pow(0.0)`, assert all equal to 1.0.

- `test_gamma_one_is_identity`: gamma=1.0 should produce weights equal to raw IoU values. Create IoUs `[0.7, 0.3]`, compute `.pow(1.0)`, assert equal to original IoUs.

**class TestLogIouCost:**
Tests for SIMO-02 (-log(IoU) regression cost).

- `test_log_iou_cost_known_values`: IoUs `[[0.5, 0.8, 0.1]]`. Expected `-log(IoU)`: `[[0.6931, 0.2231, 2.3026]]`. Assert `torch.allclose` with atol=1e-3.

- `test_log_iou_cost_perfect_match`: IoU=1.0 should give cost=0.0. Assert `-torch.log(torch.tensor(1.0) + 1e-8)` is approximately 0.0 (atol=1e-6).

- `test_log_iou_cost_near_zero`: IoU near 0 should give very high cost. Assert `-torch.log(torch.tensor(0.01) + 1e-8)` > 4.0.

**class TestSoftClassificationCost:**
Tests for SIMO-03 (RTMDet soft cls cost formulation).

- `test_rtmdet_cost_hand_computed`: 1 GT, 1 anchor, 2 classes. GT class=0, IoU=0.7. pred_score=`[[[0.6, 0.1]]]` (already sigmoid'd), soft_label=`[[[0.7, 0.0]]]`. Compute BCE and scale factor per research Example 5. Expected cost approximately `0.00716` (sum of class 0 and class 1 contributions). Assert `torch.allclose` with atol=1e-3.

- `test_rtmdet_cost_perfect_prediction`: When pred_score equals soft_label exactly, scale_factor is 0, so cost should be 0 (or very near 0). Create matching pred_score and soft_label tensors, verify cost < 1e-6.

- `test_rtmdet_cost_vs_yolox_different`: For the same inputs, verify that RTMDet cost and YOLOX cost produce different values (they use different formulations). This is a sanity check that the two paths are actually different.

**class TestFlagIndependence:**
Tests for SIMO-04 (flags independently toggleable).

- `test_config_flags_independent`: Create DINOXConfig with each flag combination: (use_soft_labels=True, use_log_iou_cost=False), (use_soft_labels=False, use_log_iou_cost=True), (use_soft_labels=True, use_log_iou_cost=True). All should be valid (no ValueError).

- `test_head_stores_flags_independently`: Create DINOXHead with use_soft_labels=True, use_log_iou_cost=False. Assert `head.use_soft_labels == True`, `head.use_log_iou_cost == False`. Then create another with reversed flags and verify.

- `test_soft_labels_training_forward_runs`: Create a DINOX model via `_make_model(use_soft_labels=True, soft_label_gamma=2.0)`. Run a training forward pass with `_make_targets()`. Assert it returns a tuple of 6 values (loss, iou_loss, conf_loss, cls_loss, l1_loss, num_fg) without error. Assert loss is finite (not NaN/Inf).

- `test_log_iou_cost_training_forward_runs`: Same as above but with `_make_model(use_log_iou_cost=True)`. Assert training forward runs and loss is finite.

- `test_all_flags_training_forward_runs`: Same with `_make_model(use_soft_labels=True, soft_label_gamma=2.0, use_log_iou_cost=True)`. Assert training forward runs and loss is finite.

**class TestGradientFlow:**

- `test_gradient_flows_with_soft_labels`: Create model with `_make_model(use_soft_labels=True)`. Run training forward, call `.backward()` on total loss. Verify at least one parameter in `model.head.cls_preds` has a non-None, non-zero gradient.

- `test_gradient_flows_with_all_flags`: Same with all flags enabled (use_soft_labels=True, use_log_iou_cost=True). Verify gradient flow.

All tests should use `torch.manual_seed(42)` where randomness is involved (model forward passes). Use small input sizes (e.g., 320x320) for speed. Mark model-forward tests with `@pytest.mark.slow` if they take >2s, but these should be fast with 320x320.
