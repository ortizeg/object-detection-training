**Tests to write:**

1. **`test_hungarian_1to1_assignment`** (DUAL-02, TEST-05):
   - Create `HungarianAssigner(alpha=1.0, beta=6.0, num_classes=2)`.
   - Set up 3 GTs and ~50 candidate anchors with known positions.
   - Call `assign(...)` and assert `num_fg == num_gt` (exactly 3).
   - Assert each GT index appears exactly once in `matched_gt_inds`.
   - Assert `fg_mask.sum() == num_gt`.

2. **`test_hungarian_empty_gt`**:
   - Call assign with `num_gt=0`.
   - Assert `num_fg == 0`, `fg_mask.sum() == 0`.

3. **`test_hungarian_returns_5tuple_contract`**:
   - Verify return types: `gt_matched_classes` is Tensor, `fg_mask` is bool Tensor of size `total_num_anchors`, `pred_ious_this_matching` is Tensor of size `num_fg`, `matched_gt_inds` is Tensor of size `num_fg`, `num_fg` is int.

4. **`test_o2o_output_shape_matches_o2m`** (TEST-05):
   - Create two DINOXHead instances: one with `use_dual_head=False`, one with `use_dual_head=True, use_soft_labels=True`.
   - Feed same FPN inputs to both in eval mode.
   - Assert output shapes are identical: `[B, N, 5+C]`.

5. **`test_o2o_inference_constant_objectness`** (DUAL-05):
   - Create DINOXHead with `use_dual_head=True, use_soft_labels=True`.
   - Run inference.
   - Extract the objectness column (index 4) from the `[B, N, 5+C]` output.
   - Assert all objectness values are 1.0 (within tolerance).

6. **`test_consistent_alpha_beta`** (DUAL-03):
   - Create DINOXHead with `use_dual_head=True, use_soft_labels=True, tal_alpha=1.5, tal_beta=3.0`.
   - Assert `head._hungarian_assigner.alpha == 1.5` and `head._hungarian_assigner.beta == 3.0`.
   - This verifies alpha/beta consistency between O2M (via config) and O2O (via HungarianAssigner).

7. **`test_dual_head_combined_loss`** (DUAL-04):
   - Create DINOXHead with `use_dual_head=True, use_soft_labels=True, lambda_o2o=1.0` (small width for speed).
   - Run training forward with targets.
   - Assert loss is finite and > 0.
   - Run same model with `lambda_o2o=0.0` -- O2O should contribute nothing, loss should equal O2M-only.

8. **`test_dual_head_separate_parameters`** (DUAL-01):
   - Create DINOXHead with `use_dual_head=True, use_soft_labels=True`.
   - Assert `cls_preds_o2o[0].weight` is not the same tensor as `cls_preds[0].weight` (separate parameters).
   - Assert they have the same shape.
   - Modify one and verify the other is unchanged (parameter independence).

9. **`test_config_lambda_o2o`**:
   - Test `DINOXConfig(use_dual_head=True, use_soft_labels=True, lambda_o2o=0.5)` validates OK.
   - Test `DINOXConfig(use_dual_head=True, use_soft_labels=False)` raises ValueError.

Use `width=0.25` and `num_classes=2` for fast test execution. Use `pytest.mark.parametrize` where it adds clarity.
