<objective>
Integrate Facebook Research's scheduler-free AdamW optimizer as an alternative to SGD+cosine in DINOXLightningModel, with proper Lightning lifecycle hooks for train/eval mode switching and checkpoint safety.

Purpose: Eliminates learning rate schedule tuning (warmup + cosine annealing) as a hyperparameter axis. Schedule-free AdamW handles warmup internally and requires no external scheduler. Fulfills OPT-01, OPT-02, OPT-03.

Output: Modified DINOXLightningModel with scheduler-free support, updated types, E6 experiment config, and unit tests.
</objective>

4. **dinox_lightning.py** -- Modify `configure_optimizers()`:
   - Change return type from `OptimizerConfig` to `OptimizerConfig` (same type, now supports optional lr_scheduler)
   - After building pg0/pg1/pg2 param groups (keep that code identical), add a branch:
   ```python
   if self._use_scheduler_free:
       from schedulefree import AdamWScheduleFree
       # Calculate warmup_steps identically to existing code
       optimizer = AdamWScheduleFree(
           pg0,
           lr=self.learning_rate,
           betas=(0.9, 0.999),
           eps=1e-8,
           weight_decay=0.0,  # pg0 = BN, no decay
           warmup_steps=warmup_steps,
       )
       optimizer.add_param_group({"params": pg1, "weight_decay": self.weight_decay})
       optimizer.add_param_group({"params": pg2, "weight_decay": 0.0})
       return {"optimizer": optimizer}
   ```
   - The `else` branch is the existing SGD + scheduler code (unchanged)

5. **dinox_lightning.py** -- Add Lightning lifecycle hooks for train/eval mode switching:
   - In existing `on_train_epoch_start()`, append at the end:
     ```python
     if self._use_scheduler_free:
         for opt in self.trainer.optimizers:
             if hasattr(opt, "train"):
                 opt.train()
     ```
   - Add new method `on_validation_model_eval()`:
     ```python
     def on_validation_model_eval(self) -> None:
         super().on_validation_model_eval()
         if self._use_scheduler_free:
             for opt in self.trainer.optimizers:
                 if hasattr(opt, "eval"):
                     opt.eval()
     ```
   - Add new method `on_validation_model_train()`:
     ```python
     def on_validation_model_train(self) -> None:
         super().on_validation_model_train()
         if self._use_scheduler_free:
             for opt in self.trainer.optimizers:
                 if hasattr(opt, "train"):
                     opt.train()
     ```
   - Add new method `on_save_checkpoint()`:
     ```python
     def on_save_checkpoint(self, checkpoint: dict[str, Any]) -> None:
         if self._use_scheduler_free:
             for opt in self.trainer.optimizers:
                 if hasattr(opt, "eval"):
                     opt.eval()
     ```
